# Kolkata Startup Map

An interactive, map-first directory for discovering Kolkata's startup ecosystem, offices, companies, and hiring opportunities.

## Prototype

The current frontend is a static prototype using Leaflet and OpenStreetMap tiles. The seed dataset is illustrative and is not presented as a complete or verified list of Kolkata startups or live vacancies.

## Roadmap

- Verified Kolkata startup/company database
- Location and geocoding confidence
- Live hiring ingestion from company career pages
- Search and filters across companies and jobs
- Startup submission and moderation
- News and ecosystem updates
- Admin tools
- Production deployment

## Run locally

Open `index.html` in a browser. An internet connection is required for map tiles.
